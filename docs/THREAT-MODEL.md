# Modèle de menace initial

Périmètre : machine x86_64 UEFI personnelle, média d’installation contrôlé par l’utilisateur et noyau obtenu depuis une source officielle vérifiable. Menaces couvertes progressivement : altération de l’image, exécution privilégiée inutile, fuite réseau silencieuse, corruption lors d’une mise à jour et accès inter-applications.

Non couvert dans la première milestone : Secure Boot avec clé MantleOS, TPM, chiffrement disque installé, sandbox graphique complète et validation formelle du bootloader.
